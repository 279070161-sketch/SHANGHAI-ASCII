# SHANGHAI-ASCII (muShanghai)

上海外滩与陆家嘴 **12 层景深 ASCII 字符天际线**，基于 `mushenzhen.xyz` 同款离屏 Canvas 缓存视差架构与内嵌 `jgs7` 像素等宽字体构建。

## 特性

- **12 层离屏 Canvas 景深缓存 (`Offscreen Layer Caching`)**：在 `259 × 96` 字符网格（`x ∈ [-129, 129], y ∈ [-48, 47]`）上按远近景深拆分为 12 个独立图层，每帧仅需 12 次 `drawImage` 即可实现 60fps 丝滑 2.5D 鼠标视差。
- **「字符雨」随机解码入场 (`Rain-in Scramble Reveal`)**：打开页面或点击屏幕任意位置时，所有非空字符按纵坐标由上至下倾泻解码入场。
- **动态图层精灵 (`Live Sprites`)**：黄浦江上的「浦江游览」号游船、「沪渡」轮渡与高架上的 `430 KM/H` 磁悬浮列车实时穿梭。
- **零外部依赖**：内嵌 `jgs7` WOFF2 字体，单文件即可直接运行或通过 `<iframe>` 嵌入作为网站全屏背景。

## 文件说明

- `index.html`：全屏自适应 12 层景深 ASCII 画布（含程序化图层生成、字符雨入场、鼠标视差与动态船只/磁浮）。
- `shanghai-background.html`：内嵌完整展开版工程 JSON 的独立背景页，兼容 `postMessage({ type: 'mushenzhen:pointer', x, y })` 与 `postMessage({ type: 'mushenzhen:replay' })`。
- `shanghai_ascii.txt`：导出的 `259 × 96` 纯文本上海字符画。
- `mushenzhen_original_ascii.txt`：原版 `mushenzhen.xyz` 导出的纯文本深圳字符画参考。
